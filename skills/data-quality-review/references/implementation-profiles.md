# 批次适用性配置

在读取模型得分之前确定任务用途、题型、目标能力、难度定位、允许工具、评分指标与方向、通过规则和可接受误差。

以随包的 implementation rubric 为基准，逐项记录 applicable 与理由。agentic 仅用于 Agent 能力任务；结构化输入输出、去重和难度要求依实际目标判断。简单题可以合格。

任务特有的正确性要求可以补充，例如代码兼容性、数值误差或答案匹配规则；补充项必须服务于公开任务契约并注明依据，不能在看到模型表现后临时删项。

真正不适用与证据不足分开：前者注明范围理由，后者以 INSUFFICIENT_EVIDENCE: 标记并计入未完成。若更改随包 rubric，保存原文、版本、哈希、差异与理由，报告明确所用适配版本。
